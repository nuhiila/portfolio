# Nouhaila Elkharfachi — portfolio

Site personnel en français, calqué sur la maquette soft-tech validée (lavande, menthe, pêche, bento arrondi). React, TypeScript et CSS, servis par Next.js.

Ce dossier est un brouillon privé. Il n’est pas publié.

## Lancer

```bash
npm install
npm run dev
```

Le serveur de développement écoute sur le port **43123**.

```bash
npm run check
npm run lint
npm run build
```

Le build produit un export statique dans `out/`.

Contact public : LinkedIn et GitHub uniquement. DocMind est le seul projet avec un dépôt vérifié.
